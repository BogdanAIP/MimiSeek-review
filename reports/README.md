# Reports

Human-readable/generated views of canonical MimiSeek data live here.

The audited Excel reviewer-statistics workbook used as the Stage 1 bootstrap source is intentionally not copied into this report directory. Its exact access-controlled source identity is repository-owned in `data/bootstrap-source.json`, which pins the ChatGPT File Library `file_id`, immutable `version_id`, byte size, and SHA-256 required for recovery and verification.

Stage 1 must recover and authenticate that exact artifact before import. After canonical text datasets exist, future workbooks/dashboards should be generated from those datasets rather than manually becoming a second source of truth.
