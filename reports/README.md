# Reports

Human-readable/generated views of canonical MimiSeek data live here.

The audited Excel reviewer-statistics workbook is also preserved here as the immutable Stage 1 bootstrap human report/import source:

`reports/bootstrap/reviewer_statistics_improvement_dataset.xlsx`

Its digest and bootstrap provenance contract are recorded in `data/bootstrap-source.json`. Stage 1 must verify that identity before import/reconciliation.

After canonical text datasets exist, future workbooks/dashboards should be generated from those datasets rather than manually becoming a second source of truth. The preserved bootstrap workbook remains historical input evidence, not the long-term canonical automation store.
